# Priya Sharma | Developer Portfolio

Personal portfolio of Priya Sharma, a final-year B.Tech IT student and MERN stack developer. Built from scratch with vanilla HTML, CSS and JavaScript, with no frameworks and no UI libraries.

**Live:** [portfolio-pi-ashen-s70co9o8a2.vercel.app](https://portfolio-pi-ashen-s70co9o8a2.vercel.app/)

## Sections

- **Hero:** intro, availability badge, profile photo with floating tech chips (React, Node.js, MongoDB), and buttons for projects, resume download and contact
- **About:** short background
- **Skills:** grouped into Frontend, Backend, Database and Tools
- **Projects:** problem, solution, tech stack and links for each project
- **Experience:** internship, training and open-source timeline
- **Contact:** email, LinkedIn, GitHub and resume

## UI Features

- Floating particle background generated with JavaScript
- Sticky navbar with blur effect and smooth-scroll anchor navigation
- Hero entrance animation on page load
- Shine-sweep and lift hover effect on primary buttons
- Lift and highlight hover effect on project cards
- Responsive layout with CSS Grid and Flexbox, with a mobile-specific hero and navbar
- Keyboard focus outlines on links and buttons
- Respects `prefers-reduced-motion`: animations, transitions and particles are turned off for users who request it

## Tech Stack

HTML5, CSS3 (Grid, Flexbox, custom properties, keyframe animations), Vanilla JavaScript. Deployed on Vercel.

## Run Locally

```bash
git clone https://github.com/priya-12340/Portfolio.git
cd Portfolio
```

Then open `index.html` in a browser, or use the VS Code Live Server extension (default port 5500).

No build step and no dependencies to install.
