# Priya's Portfolio

A 3D animated developer portfolio built from scratch using vanilla HTML, CSS, and JavaScript — no frameworks, no libraries.

## Features
- 3D flip card hero section (CSS `transform-style: preserve-3d`)
- Rotating skills cube built with 6 individually positioned CSS 3D faces
- Mouse-follow tilt effect on project cards (JS + CSS `perspective`)
- Scroll-reveal animations using `IntersectionObserver`
- Animated floating particle background
- Fully responsive layout with CSS Grid

## Tech Stack
HTML5, CSS3 (3D Transforms, Grid, Flexbox), Vanilla JavaScript
